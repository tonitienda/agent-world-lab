# Agent Terrarium Modern Skin

`terrarium_skin.grf` is the compiled graphics pack supplied for the
[Forest to Market design](https://claude.ai/artifact/SdRVUsNCVn9niVGPvBvREH#page-dcb81aee8d83).

OpenTTD 15.3 identifies it as GRF `41540101`, version 1. The native capture test
loaded it as a static NewGRF over OpenGFX2 Classic using the 32bpp blitter. It
replaces temperate trees, ground and road vehicle sprites.
