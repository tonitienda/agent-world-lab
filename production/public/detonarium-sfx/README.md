# Original Detonarium effects

These WAVs are deterministic previews generated by `src/detonarium/sfx.ts`:
place, explosion, elimination, pickup, collapse, slow-in, slow-out.

No third-party samples or recordings are used. See `manifest.json` for provenance.
Change the generator to revise the sound set; the episode stem is synthesized from
that same code. Editing these preview WAVs alone does not change the stem.

Episode cue sheets apply quieter per-kind gains, combine near-simultaneous chain
blasts and duck effects beneath speech. Raw WAV previews are louder than the final
mix. See `docs/detonarium-sound-effects.md` for usage and verification.
